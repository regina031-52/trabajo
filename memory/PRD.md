# Refugios A* - PRD

## Problem Statement
App para encontrar ruta más corta al refugio (escuela) más cercano usando A*.
**Ciudad Renacimiento** (CP 39715), Acapulco de Juárez, Guerrero.
Centro: 16.8971, -99.8199

## Implemented (Feb 2026)
- [x] Red peatonal real OSM (4318 nodos, 12124 aristas)
- [x] 18 escuelas/refugios con ubicaciones reales en calles correctas
- [x] Algoritmo A* personalizado con instrucciones paso a paso
- [x] Mapa interactivo Leaflet, búsqueda por calle, GPS, click en mapa
- [x] Panel colapsable, kit de emergencia, lista de todas las escuelas
- [x] Script Python standalone para compartir con compañeros
