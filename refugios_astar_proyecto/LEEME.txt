================================================================
  REFUGIOS A* - Ciudad Renacimiento, Acapulco (CP 39715)
  Encuentra el refugio mas cercano usando el algoritmo A*
================================================================

REQUISITOS:
  - Python 3.8 o superior (descargar de https://www.python.org)
  - Al instalar Python, MARCAR la casilla "Add Python to PATH"

INSTALACION (una sola vez, abrir CMD o Terminal):
  pip install networkx matplotlib

EJECUTAR:
  1. Descomprimir esta carpeta
  2. Abrir CMD o Terminal
  3. Navegar a la carpeta:  cd refugios_astar_proyecto
  4. Ejecutar:  python refugios_astar_standalone.py

ARCHIVOS:
  refugios_astar_standalone.py  -> Script principal (codigo Python)
  data/escuelas.json            -> 19 refugios verificados
  data/nodos_calles.json        -> 8558 nodos de calles reales (OSM)
  data/aristas_calles.json      -> 23332 aristas (conexiones entre calles)

QUE HACE:
  1. Te pide escribir el nombre de tu calle
  2. Calcula con A* la ruta mas corta a los 19 refugios
  3. Muestra el refugio mas cercano con instrucciones paso a paso
  4. Lista todos los refugios ordenados por distancia
  5. Muestra kit de emergencia
  6. Genera imagen "ruta_refugio.png" con el mapa de la ruta
